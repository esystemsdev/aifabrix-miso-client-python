- `rule,file,line,column,severity,message,symbol,status,batch,owner,notes`

Row lifecycle:
- `open` -> `in_progress` -> `fixed`
- `open`/`in_progress` -> `deferred` (must include reason + next action in `notes`)

Update rules:
- Every touched diagnostic row must get `batch` and `owner`.
- No row may remain `in_progress` at session end.
- `deferred` rows require explicit technical reason and follow-up pointer.
- For this plan, `owner` is always `agent-main` (single-agent execution only).

## Rule-by-Rule Remediation Catalog (Execution Guidance)
### reportUnknownMemberType / reportUnknownVariableType / reportUnknownParameterType / reportUnknownArgumentType
- Preferred fixes: explicit type annotations, typed intermediates, Protocol/TypedDict where structure is stable, narrowed unions before use.
- Avoid: broad `Any` widening and blanket ignores.

### reportMissingParameterType / reportAny / reportExplicitAny / reportUntypedFunctionDecorator
- Preferred fixes: complete function signatures, decorator typing wrappers, gradual elimination of `Any` in public/service boundaries.
- Avoid: replacing unknown types with `Any` without narrowing strategy.

### reportAttributeAccessIssue / reportOptionalMemberAccess / reportOptionalSubscript / reportPossiblyUnboundVariable
- Preferred fixes: guard-first flow, explicit initialization, branch-local helper extraction, typed `.get()` defaults for mappings.
- Avoid: cast-based non-null assertions without runtime proof.

### reportArgumentType / reportCallIssue / reportReturnType
- Preferred fixes: call-site narrowing, signature alignment, consistent return contracts, safe conversions.
- Avoid: changing behavior silently to satisfy the checker.

### reportMissingImports
- Preferred fixes: add real dependency when required, or isolate truly optional paths with explicit fallback behavior.
- Avoid: ignoring import failures in core paths.

### Cleanup rules (`reportUnused*`, `reportUnreachable`, `reportUnnecessary*`, `reportImportCycles`, private usage rules)
- Preferred fixes: remove dead paths, simplify guards, break cycles through local interfaces.
- Avoid: suppressions as first response.
